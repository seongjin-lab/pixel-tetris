# 픽셀 테트리스

터미널에서 즐기는 색상 블록 게임입니다. 착지 미리보기는 현재 블록과 같은 모양을 어두운 색으로 보여줍니다. 채운 줄은 반짝인 뒤 양옆에서 가운데로 사라집니다. 10줄마다 낙하 속도가 빨라집니다.

블록 회전, 고정, 한 줄 삭제, 동시 삭제, 콤보, 게임 종료에 각각 다른 8비트 효과음이 재생됩니다. 리눅스에서 효과음을 들으려면 오디오 환경에 맞는 `pw-play`, `paplay`, `aplay` 중 하나가 필요합니다.

블록을 놓을 때마다 연속으로 줄을 지우면 두 번째부터 콤보 연출이 나오고, 보너스는 `50 × (연속 횟수 - 1) × 레벨`점입니다. 줄을 지우지 못한 블록을 놓으면 연속 횟수가 초기화됩니다. 한 번에 두 줄 이상 지우면 동시 삭제 연출과 줄 삭제 점수가 함께 표시됩니다.

## 실행

[릴리스](https://github.com/seongjin-lab/pixel-tetris/releases/latest)에서 Apple Silicon 맥용 앱이나 CPU에 맞는 리눅스 파일을 내려받을 수 있습니다. 맥에서는 압축을 풀고 **픽셀 테트리스** 앱을 열면 전용 창이 뜹니다. [리눅스 설치 안내](LINUX.md)에는 배포판별 실행 방법이 있습니다.

Go 1.22 이상이 설치된 환경에서는 터미널 버전을 소스에서 실행할 수 있습니다.

```sh
go run .
```

맥에서 전용 창 앱을 빌드하려면 Go와 Xcode 명령줄 도구를 설치한 뒤 아래 명령을 실행하세요. 앱은 `build` 폴더에 만들어집니다.

```sh
./macos/build.sh
```

터미널은 47열 × 24행 이상으로 열어 주세요.
시작 화면에서 `게임 시작`을 클릭하거나 Enter를 누르면 게임이 시작됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← / → 또는 A / D | 좌우 이동 |
| ↑ 또는 W | 시계 방향으로 회전 |
| ↓ 또는 S | 한 칸 내리기 |
| 스페이스 | 즉시 낙하 |
| P | 일시정지 / 계속 |
| R | 다시 시작 |
| M | 효과음 켜기 / 끄기 |
| Q / Esc | 종료 |
